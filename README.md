
Ajwaa Trading & Contracting Website Upload Guide

Folder structure:
ajwaa_site/
  index.html
  style.css
  assets/
    crane_PNG8.png

Important:
1. Put your crane image file inside the assets folder.
2. Rename the image exactly as: crane_PNG8.png
3. Upload index.html, style.css and the assets folder to your hosting provider or GitHub Pages repository.
4. Open index.html in a browser to test locally.

No WhatsApp Quote button is included in this version.
